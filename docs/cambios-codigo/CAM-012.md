# CAM-012 — Corregir lectura del manifiesto Android en PowerShell

## Motivo y autorización
Corrección dentro de la preparación Android autorizada por el usuario. El script rechazó el manifiesto debug estándar generado por Flutter.

## Cambio
En scripts/configurar-android-documentos.ps1 se obtiene el nombre del elemento mediante XmlNode.get_Name(). El adaptador XML de PowerShell puede resolver Name como el atributo android:name y devolver android.permission.INTERNET en lugar de uses-permission.

Se mantienen las validaciones de permisos, atributos, actividad y configuración de red, así como los respaldos antes de escribir. Si Android ya existe, el script omite su generación.

## Verificación
Revisión del cambio: las dos comparaciones utilizan el nombre nativo del elemento; no se modifica el resto del script. PowerShell y Flutter no están disponibles en este entorno; la ejecución en Windows queda pendiente.

Desde la raíz del repositorio, actualizar con git pull --ff-only y ejecutar:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\configurar-android-documentos.ps1
```
Resultado esperado: Android preparado y ruta del respaldo.

## Reversión
Restaurar la versión anterior del script desde Git. La corrección no altera por sí sola los archivos Android locales.
