# Fases
1. Interfaz base: estilo, navegación adaptable y vistas por rol. En curso.
2. Flujos visuales: acceso, carga, consulta, historial y revisión. Datos sintéticos y simulaciones identificadas.
3. Backend y acceso: Express/TypeScript, PostgreSQL, sesiones y permisos reales.
4. Documentos: S3 privado, validaciones, metadatos y auditoría; flujo completo.
5. IA: modelo autorizado, extracción, revisión y explicación; chat solo con autorización.
6. Calidad: consolidar pruebas ejecutadas durante todas las fases y correcciones autorizadas.
7. Docker y entrega: entorno reproducible y preparación para traslado al oficial.
Ninguna fase se declara terminada sin comprobaciones. Registrar modificaciones autorizadas en docs/cambios-codigo.
